## ✨ Что это?

**Architect — Agent Symphony** — это настольное приложение, которое превращает Claude Agent SDK в **иерархическую организацию AI-агентов, которой вы управляете как компанией.**

Вместо общения с единственным ассистентом вы запускаете **организационную структуру из специализированных агентов**: главный архитектор координирует руководителей проектов, каждый руководитель командует собственными постоянными специалистами, консультируется с панелью доменных советников и отправляет одноразовых исполнителей — всё это параллельно, всё в одной кабине управления, с полной прозрачностью затрат и управлением контекстом уровня Claude Code.

Представьте это как **центр управления полётами для команды Claude-агентов** — специально созданный для оркестрации реальной многопроектной работы над программным обеспечением.

### 🧭 Где это применимо

Если вы пользовались **Claude Code**, **CrewAI**, **AutoGen** или **LangGraph**: это фреймворки и CLI, которые вы *программируете*. **Architect — Agent Symphony** — это **настольная кабина управления, где сама оркестрация *и есть* продукт** — вы наблюдаете за постоянной организацией агентов в реальных проектах и командуете ею, с живой прозрачностью затрат и контекста, вместо того чтобы писать код оркестрации. Он построен напрямую на официальном **[Claude Agent SDK](https://docs.anthropic.com/en/api/agent-sdk)** (внутри процесса, без отдельного CLI), поэтому вы получаете поведение уровня Claude Code с надстроенным сверху интерфейсом для множества агентов и проектов.

**Ключевые слова:** оркестрация Claude-агентов · оркестрация DeepSeek-агентов · LLM-агенты с несколькими провайдерами · мультиагентный AI · агентные рабочие процессы · автономные кодирующие агенты · альтернативный интерфейс для Claude Code · настольное приложение DeepSeek V4 · AI-команда разработки · инструменты MCP.

## 🌟 Чем он отличается

- 🧬 **Навыки для каждого агента** — каждый агент загружает **собственные** файлы навыков. Вы создаёте настоящего специалиста с глубокими доменными знаниями, а не универсального чат-бота с бейджиком на груди.
- 🤖 **Навыки назначаются автоматически по задаче** — когда руководитель создаёт нового специалиста, тот **автоматически наследует подходящие доменные навыки** для работы: специалист по дизайну получает навыки дизайна, специалист по безопасности — навыки безопасности.
- 🗂️ **Переключайтесь между проектами как между вкладками браузера** — перемещайтесь между несколькими **живыми проектами и параллельными сессиями**, как между вкладками Chrome, каждая со своими агентами, контекстом, историей и счётчиком затрат.
- 💬 **Агенты общаются друг с другом** — руководители консультируются с советниками и обмениваются сообщениями с другими руководителями проектов; работа *согласовывается между агентами*, а не просто диктуется вами сверху вниз.
- 🌙 **Самосовершенствование по ночам** — главный Architect может **каждую ночь анализировать собственную кодовую базу и автономно предлагать / внедрять улучшения**, так что оркестратор продолжает становиться лучше, пока вы спите.
- ⚡ **Параллельность по умолчанию** — независимые подзадачи распределяются сразу между множеством агентов, после чего дирижёр объединяет результаты.

## 🚀 Возможности

### 🧠 Инженерия контекста уровня Claude Code
- **Нативное уплотнение SDK** — контекст уплотняется *внутри той же сессии* (с сохранением идентификатора сессии) так же, как это делает Claude Code, с устаревшим запасным механизмом «суммировать и перенести вперёд», благодаря чему агент **никогда не теряет свою рабочую память**.
- **Отслеживание токенов и затрат по сессиям и агентам** — каждый ход показывает свежие / прочитанные из кэша / записанные в кэш токены и точную стоимость в долларах США.
- **Дизайн с учётом кэширования промптов** — стабильные наборы инструментов и удобная для кэша компоновка промптов поддерживают высокий процент попаданий в кэш (дешёвые чтения вместо дорогих перезаписей).
- **Ленивые группы инструментов** — агенты загружают наборы инструментов по требованию (`load_toolset`), чтобы держать минимальный потолок токенов на ход низким.

### 🔀 Маршрутизация моделей между провайдерами (Claude + DeepSeek)
- **Два провайдера, одна кабина** — запускайте агентов на **Anthropic Claude** (Opus / Sonnet / Haiku) **или DeepSeek V4** (`deepseek-v4-pro` / `deepseek-v4-flash`). Выбирайте модель для каждого агента из одного и того же выпадающего списка.
- **Автоматический приоритет провайдера** — если задан API-ключ DeepSeek, сначала используется DeepSeek; иначе API-ключ Anthropic; иначе ваш вход через Claude Pro/Max. Без изменений в коде.
- **Разумные значения по умолчанию для ролей на DeepSeek** — руководители, главный архитектор и советники по умолчанию используют **DeepSeek V4 Pro**, а одноразовые специалисты/исполнители — более дешёвый **DeepSeek V4 Flash**.
- **Как это работает** — DeepSeek доступен через свою **совместимую с Anthropic конечную точку** (`https://api.deepseek.com/anthropic`), поэтому тот же формат запросов Agent SDK, вызовы инструментов, режим размышления и окно контекста на 1M токенов работают без изменений. Стоимость в долларах США по каждой модели и каждому токену корректно отслеживается для каждого провайдера.
- **Переключение на лету** — меняйте модель работающего агента с Claude на DeepSeek (или обратно) посреди сессии; маршрутизация следует за выбранной моделью при каждом запросе.

### 🕸️ CodeGraph — семантический интеллект кода
Встроенный граф кода поверх ваших репозиториев (на базе **tree-sitter** для TypeScript, JavaScript, Python, PHP, C#, Dart и Svelte + **SQLite FTS** + эмбеддинги):
- `code_search`, `code_node`, `code_callers`, `code_callees`, `code_impact`, `code_imports`, `code_files`, `code_stats`
- Агенты запрашивают граф вместо слепого grep — быстрее, дешевле, точнее. Автоматически переиндексирует при изменении файлов.

### 👥 Мультиагентная оркестрация
- **Параллельное делегирование** — независимые подзадачи распределяются между несколькими агентами в одной партии.
- **Постоянные специалисты** с собственной идентичностью, навыками и историей чата.
- **Межагентное взаимодействие** — руководители консультируются с советниками и обмениваются сообщениями друг с другом (`talk_to_chief`).
- **Просмотр активности в реальном времени** — кликните по любому работающему специалисту, чтобы увидеть полученный им промпт и то, чем он занят прямо сейчас.
- **Фоновое делегирование** — запустите долго работающего специалиста и продолжайте общаться с руководителем; результаты вернутся, когда будут готовы.

### 🗂️ Кабина с несколькими проектами и сессиями
- Управляйте множеством проектов, у каждого свой руководитель и агенты.
- Несколько параллельных сессий на агента в стиле Claude Code, у каждой свой контекст, затраты и история.
- Сессии **никогда не сбрасываются молча** — ваш контекст переживает остановки, перезапуски и повторные попытки.

### 🛠️ Инструменты для реальной работы оператора
- **SSH / деплой** — инструменты для отправки проектов на серверы.
- **Хранилище секретов** для учётных данных (никогда не коммитятся).
- **Навыки по ролям** — прикрепляйте доменные файлы SKILL к специалистам и советникам.
- **Автономный режим** — поставьте агенту многодневную цель и дайте ему работать, ставьте на паузу и возобновляйте.
- **Автоматизация браузера и генерация изображений** через Playwright.
- **Контроль бюджета** с автоматическим переходом на более дешёвую модель при достижении лимита.

### 🎨 По-настоящему приятное настольное приложение
Создано на **Tauri + SvelteKit** — быстрая, нативная настольная кабина управления (не вкладка браузера) с чистым, специально спроектированным тёмным интерфейсом: градиентные заголовки, списки агентов в виде карточек, живые датчики токенов, обозреватель CodeGraph, отчёты и заметки.

## 🔑 Аутентификация — план Claude, ключ Anthropic *или* ключ DeepSeek

Architect — Agent Symphony работает на официальном **Claude Agent SDK** и поддерживает **два провайдера моделей**. Он выбирает провайдера в следующем порядке приоритета:

- 🟣 **API-ключ DeepSeek** *(наивысший приоритет, когда задан)* — добавьте свой ключ DeepSeek во встроенную в приложение панель **API keys** (хранится локально в `providers.json`, никогда не коммитится). После этого агенты работают на **DeepSeek V4 Pro / Flash** через совместимую с Anthropic конечную точку DeepSeek. Самый дешёвый путь; модели Claude остаются доступными в выпадающем списке, если у вас также есть вход в Claude.
- 🟢 **Подписка Claude Pro / Max** *(рекомендуется для пользователей Claude)* — войдите один раз через CLI Claude (`claude login`). Использование засчитывается в вашу существующую **квоту Pro/Max — без API-ключа, без оплаты за токены.**
- 🔵 **API-ключ Anthropic** *(оплата за токены)* — задайте `ANTHROPIC_API_KEY`. Лучше всего для команд/автоматизации с биллингом через Console.

> ⚠️ Если `ANTHROPIC_API_KEY` задан в вашем окружении, он **имеет приоритет** над вашей подпиской Claude. Чтобы использовать план Pro/Max для моделей Claude, оставьте эту переменную незаданной (и выполните `claude logout` → `claude login` с учётной записью Pro/Max). Ключ DeepSeek управляется отдельно в приложении и влияет только на запросы к моделям DeepSeek.

Локальный прокси приложения только оптимизирует кэширование промптов — он **никогда не касается ваших учётных данных и пути обновления OAuth**, поэтому оба режима аутентификации работают «из коробки».

## ⚙️ Конфигурация

- **Аутентификация** — ключ DeepSeek (в приложении), вход через Claude Pro/Max *или* `ANTHROPIC_API_KEY` (см. [Аутентификация](#-authentication--claude-plan-anthropic-key-or-deepseek-key)).

> Каталоги `.github/`, `.team/` и каталоги данных времени выполнения игнорируются git — никакие учётные данные или данные сессий никогда не коммитятся.
